# ServAll interactive case studies

Self-contained HTML scenarios for the HR2 "Manage Job-related Training" course. Each folder holds one `index.html` with all images and audio embedded.

Published with GitHub Pages from the root of this repository:

- `/` – index page listing the scenarios
- `/internal-training-gaps/` – Case Study 2: Internal Training Gaps at a VIP Charter Operator
- `/silence-isnt-golden/` – Case Study 1: Silence Isn't Golden
